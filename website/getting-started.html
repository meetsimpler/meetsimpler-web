Your first meeting, step by step.

Start with a short practice session. You will activate the Windows app, choose where records are saved, set up transcription and AI, then check that your voice and meeting audio are captured.

Keep this guide open beside MeetSimpler. Button names below match the desktop app. See the app snapshots for a look at the interface.

Use it beyond meetings.

The same controls work for lectures, podcasts, interviews and personal notes. The desktop app keeps its current meeting labels.

  • Start meeting: capture a live lecture, discussion or spoken note using your selected audio sources.
  • Import audio: choose an audio or video file for local transcription instead of live capture.
  • AI chat: enable both Meeting context: On and Transcript context: On in the sidebar, then ask for study notes, key ideas or explanations. Default summary formats focus on meetings; AI chat and custom prompts let you request another format.

Video imports transcribe the audio track. Add screenshots or other images through Meeting context config when visual information matters.

Explore the use cases

Before you start

  • A Windows PC: check the requirements listed with the release you download.
  • An internet connection: needed for account activation, speech model downloads and cloud AI requests.
  • A microphone and a test audio source: a headset is useful for keeping speaker playback out of your microphone.
  • A folder with enough free space: meeting recordings and downloaded speech models can take substantial space.
  • Your own AI provider credentials: needed for AI chat and summaries. Local speech recognition uses an installed speech model separately.
Start with your own practice audio.

Before recording other people, tell them what will be captured and obtain their permission. Read the recording policy before a real meeting.

1 Download and open MeetSimpler

  1. Use Windows downloads on the homepage for the installer, or choose the portable ZIP from GitHub Releases.
  2. Read the release requirements before downloading. The installer and portable ZIP are alternative ways to run the Windows app.
  3. If you downloaded an installer, follow its installation instructions. If you downloaded a ZIP archive, extract the whole archive into a folder before running the app. Keep the included files together.
  4. Open MeetSimpler.exe. The first screen asks you to sign in.

App will not open? Check security software blocks.

You are ready for the next step when the MeetSimpler sign-in window appears.

2 Sign in and activate desktop access

  1. Read the Terms and Privacy Policy, then select the acceptance checkbox in the desktop sign-in window.
  2. For email sign-in, enter your email and password and select Sign in. If you need an account, select Create account. Follow any email confirmation instructions, then sign in.
  3. Alternatively, select Continue with Google or Continue with GitHub in the desktop app. Complete sign-in in the browser tab opened by the app.
  4. When the browser reports that the desktop handoff succeeded, return to MeetSimpler. The app completes activation and continues to setup.

You can also register on the account page. Signing in on the website alone does not activate the desktop app: return to the app and complete its sign-in flow.

Account access and AI access are separate.

The app checks for updates at startup. Install any required update it finds before continuing. If the check is unavailable, a valid seven-day access permit still allows offline startup. Connect to activate or renew access while the free beta remains available. Cloud AI requires an internet connection and your provider's credentials; provider charges are separate.

You are ready when the app opens the first-run meeting folder screen, or the dashboard if you have already chosen a folder.

3 Choose where your meetings are saved

  1. In the welcome screen, choose Use suggested folder for the displayed location, Select folder for an existing folder.
  2. Check the displayed path. Choose a location you can access easily and that has room for recordings and model downloads.
  3. Select Continue. MeetSimpler opens the dashboard.

This is your meeting parent folder. Each new meeting gets its own timestamped folder beneath it. Recordings, transcripts, summaries and other meeting files are stored locally. Use Meeting folder from the dashboard to find the current meeting's files.

To change the location later, open Settings, choose the meeting parent folder and select Apply folder change. Read any relocation instructions shown by the app before continuing.

You are ready when the dashboard shows your selected meeting folder.

4 Install and select a speech model

Speech recognition, also called STT (speech to text), turns captured audio into a local transcript. Selecting an AI chat model does not install a speech model.

  1. Open Settings from Meeting Control and find Speech recognition (STT).
  2. Use Use CPU only for a first setup without a working CUDA environment. Use Use GPU with CUDA only when the app's CUDA checks confirm support.
  3. Select Install and manage STT models.... Locate the model required for your chosen device and select Install in its Action column. The app currently uses Whisper base as the CPU default and Qwen3-ASR-0.6B as the CUDA default.
  4. Keep the internet connection available while the model and its packages download. Wait for its status to show Installed. If it reports an incomplete installation, use the offered reinstall action.
  5. Return to Settings. In your device's STT model selector, choose an installed model. Leave the default STT pipeline settings for your first practice session.
  6. Allow the settings change to save before closing Settings. Back on the dashboard, check that the STT model is selected rather than showing None (action required).

Repair (no model download) repairs the selected model's software packages. It does not download missing model files. If the manager reports Reinstall required, use Reinstall to download and validate the model again.

Explore supported local models and how overlap decoding works.

The speech model loads when you select Start meeting. The STT control also lets you load or restart it. A first load can take longer than later uses; check the model status before expecting transcript text.

STT installation or loading failed? Check security software blocks.

You are ready when your selected speech model is installed and named on the dashboard.

5 Connect AI chat and summaries

MeetSimpler connects to an OpenAI-compatible chat API. Use the API connection details provided by your chosen provider, rather than a normal chat website login.

  1. Open Settings → AI provider config.
  2. Enter the provider's Server / API base URL. Include its API prefix, such as /v1, as instructed by the provider.
  3. Paste your provider's API key. Keep it private. It is separate from your MeetSimpler account password.
  4. Select Select AI model and choose a model available to your account. If you use Edit manually, enter the exact model identifier supplied by the provider.
  5. Select Test connection. Read the result. Resolve a rejected key, unavailable model or incorrect URL before continuing.
  6. Select Save after the connection test succeeds.
  7. Open Settings → AI context settings. Review the information included in AI chat and each type of summary. Use Customize if you want to change optional context. Files you submit directly in AI chat are sent independently of the meeting context file setting.

In Select AI model, use Filter by model name or ID to narrow the list, then double-click a model or choose Select model. Return to AI provider config, test the connection and Save to apply your choice.

For the first meeting, keep the existing timed-summary interval. Adjust it later under Settings → Live summary and analysis.

Understand what leaves your computer.

Local meeting storage and local transcription do not make cloud AI requests local. Chat and summaries send the request content to your configured AI provider. Review your context settings and provider policy before using real meeting information.

You are ready when Test connection succeeds, the configuration is saved and the dashboard shows your AI model.

6 Choose what the meeting will hear

  1. Connect your headset or microphone and open the meeting app or test playback source you want to capture.
  2. In Meeting Control, select the button beginning with Audio sources: to open Transcript source.
  3. Select a microphone to capture your voice, if needed. Select either system output audio or an available app output to capture the other side of an online call.
  4. Double-click an audio source row or use its checkbox to toggle it. Check Selected sources, then select Confirm.

Available application outputs can include your meeting app, browser or media player. Open the application and start playback so it appears in the source list. Select its output to capture audio from that application, or select system output to capture all audio played by the computer.

The Voice input control is for chat voice input. Configure meeting capture through Audio sources:. Use headphones if playback is also reaching your microphone and causing repeated speech.

You are ready when the Audio sources button reflects the microphone and output you intend to use.

7 Run a short practice meeting

  1. Select Start meeting. If a setup reminder appears, complete the missing settings before continuing.
  2. Check that the control changes to Click to stop meeting, the recorded time advances and the STT status becomes ready. Confirm recording is on if you want saved audio.
  3. Say a few clear sentences into your selected microphone. For example: “This is a practice meeting. We will review the beta on Friday. I will collect feedback before the next meeting.”
  4. If you selected an output source, play a short spoken clip or have a consenting test participant speak in the call.
  5. Watch Live Transcript. Temporary recognition can appear first; confirmed text should follow as the model processes the audio. Check that both your voice and the selected output appear when both are selected.
  6. If text is missing, check the source selection, device mute state and STT status before recording a full meeting.
  7. Select AI chat. In its sidebar, check that Meeting context: On is enabled. Select Transcript context: Off to change it to Transcript context: On if needed. This includes the meeting transcript in your chat request to the configured AI provider.
  8. Type a question such as “What decisions have we made so far?” and select Send. Review the reply against the transcript.

Automatic summaries appear as their configured intervals are reached and AI requests complete. A short practice session may finish before an automatic summary is due; you can request a final summary after ending it.

Use Click to stop meeting to finish capture.

Stop recording stops saving audio while meeting capture and transcription can continue. Stop STT stops speech recognition. Neither is the same action as ending the meeting.

The practice worked when you can see the expected speech in the transcript and, if AI is configured, receive a chat reply.

8 Finish, review and keep the results

  1. Select Click to stop meeting. Wait for the app to finish saving the meeting before requesting a final summary or opening another meeting.
  2. Open AI chat and select Final summary. Wait for the request to finish. The resulting summary is saved in the meeting folder as final_summary.md.
  3. Read the transcript and summary. Check names, numbers, decisions, owners and due dates against what was actually said. Correct your notes before sharing them.
  4. For a specific part of the discussion, select Partial summary, choose the time range and select Generate summary.
  5. Select Meeting folder to inspect your records. The confirmed transcript is saved as transcript.md; generated summaries and saved audio remain with the meeting.
  6. If audio was saved, select Export full audio to produce a complete WAV file. Choose its destination and wait for export to finish.

Ending a meeting saves the available records; requesting Final summary is a separate AI action. You can retain a transcript even if an AI request fails and retry the summary once the provider connection is working.

You have completed your first meeting when you can open its folder, find the transcript and review any generated summary or exported audio.

Manage your account

Use Tab to move between controls and Enter or Space to activate the focused button. A successful email login, logout or account deletion moves keyboard focus to the newly shown heading. A background session refresh keeps your current focus. After a retryable request error, focus returns to the control you used if you have not moved elsewhere.

Use the account page to create an account or log in with email, Google or GitHub. Website sign-in is separate from desktop activation; start browser pairing from the Windows app when activating it.

Forgot your password? On the account page, enter your email and use the Forgot password? button. Open the email link, enter a new password and select Save new password. After success, log in again. If recovery fails or times out, request a new link from the account page.

For an email account, Change password asks for your current password and a matching new password entered twice. Google-only or GitHub-only accounts do not show this password form; manage those credentials with the sign-in provider.

Log out of this browser ends the current browser session. Log out on all devices ends account refresh sessions across devices. Existing desktop offline permits can remain valid until they expire; logging out does not remove local meeting files.

To permanently delete your account, choose Delete my account, review the warning, type DELETE exactly and select Permanently delete my account. Cancel closes the confirmation without deleting anything. Account deletion cannot be undone; recordings and meeting files on your computer are kept.

If an account request times out and the controls remain disabled, reload the account page. For a desktop browser sign-in timeout, return to the Windows app and start sign-in again.

Import audio or video

Import a recording instead of capturing live audio. Importing creates a new meeting folder and leaves the original media unchanged. Speech recognition runs locally with your installed speech model; optional AI analysis uses your configured provider.

  1. End the current meeting and select an installed speech model. Choose Import audio in Meeting Control, then Audio file... to select an audio or video file. Video imports transcribe the audio track; they do not analyze video frames.
  2. For several recordings, choose Folder of audio segments... and select their folder. Number ordinary filenames in playback order before importing. Saved MeetSimpler meeting folders use their recorded audio tracks.
  3. Follow the separate progress stages for importing the file, loading the speech model and transcribing. A first model load can take longer. Select Cancel if you want to stop the import.
  4. Wait for the successful import message. Use Open folder to inspect the audio and transcript, or Close to return to the dashboard. A progress bar alone does not confirm that the transcript has been saved.
  5. Review the transcript, then use AI chat, Final summary or Live analysis as needed. The imported meeting remains paused; use Resume meeting only when you want to add new live audio.

AI chat

Open AI chat and review Meeting context and Transcript context before sending a question. Enable both to ask about the meeting transcript. Voice input can send the current draft automatically; review its settings before dictating.

Press Enter to send a message and Shift+Enter to add a new line. Clear input removes unsent text but keeps draft attachments. Remove unwanted draft files from the file list before sending.

Right-click the message box and choose Attach files, or drag supported images, PDFs or text files into the chat window. Wait for attachment processing to finish before sending. The file list distinguishes draft attachments, submitted files and files returned by the provider.

Select New chat to start another conversation in the same meeting, and confirm when prompted. Earlier saved chat sessions remain in the meeting folder; starting a new chat does not start a new meeting.

Each question and reply share a foldable block. Reopening a conversation expands its newest question first. Use Fold all or Unfold all in the header, or open individual blocks. The active block has a highlighted title.

Cancel stops that question's pending reply. Update regenerates its answer using the submitted attachments; partial and final summaries keep their original operation and time range. Remove deletes the question and reply from the saved conversation and cancels its request. Other requests continue, and local attachment files are kept.

Select a sent or received file link to open it, or Open folder to locate it. In Settings → Other settings, Render Markdown in AI Chat controls formatted answer display. Turning it off changes the display without changing the saved answer.

AI request settings and limits

For advanced options, open Settings → AI provider config → Detailed config. Select Done to return, then Save in AI provider config to apply the changes.

AI text input budget checks a conservative estimate of text, chat history and tool instructions. Images and PDFs are sent unchanged and excluded from that estimate. When the budget is exceeded, the request is rejected without trimming the context.

To resolve an input-budget error, choose a shorter transcript time range or disable unneeded text context. Increase the budget only if your selected model can accept the request. Provider limits still apply to both text and media.

Request timeout defaults to 180 seconds and includes provider queueing, request processing and returned files. If a request times out, check the provider status and request size before retrying, or adjust the timeout in Detailed config. Use Cancel on a chat block to stop that request.

Use provider default output length sends no app output limit; provider limits and credit requirements still apply. To set a smaller response limit, turn that option off and enter Maximum output tokens. Run Test connection, then Save.

Chat voice input

Voice input uses your installed speech model to turn microphone audio into chat text. AI replies use your configured provider and may incur charges. Automatic sending is on by default after 1.5 seconds of silence following speech.

  1. In AI chat, open Mic source, choose a microphone and select Confirm. Install and select a speech model first if Voice input is unavailable.
  2. To review drafts before sending, switch off Voice auto send. In AI voice config, turn off Enable voice commands and select Save. With automatic sending on, a pause sends the current draft, including typed text and draft attachments.
  3. Select Voice input and wait for the listening status. Dictate your message. The microphone keeps listening after a message is sent; select Stop voice input when finished. Stopping keeps the available draft text.

Open AI voice config to change microphone sensitivity, the silence interval, automatic sending and voice commands, then select Save. Saved changes apply while listening. Sensitivity also affects meeting microphone transcription; system output audio is unaffected.

Voice commands are enabled by default. Say a configured phrase separately, then pause, to delete the last voice segment, clear all input or send the message. Review or edit the phrases in AI voice config; they do not change with the interface language. Turn off Enable voice commands to dictate those phrases as ordinary text.

Voice input pauses the meeting microphone.

While chat voice input listens, the meeting microphone is temporarily excluded from meeting capture and transcription. Selected system or app output audio continues. Stop voice input to restore the meeting microphone.

Timed and chunk summaries

Timed summary in the main window summarizes each new time span as bullet points. It starts with meetings by default. Use Timed summary: On to turn it off without stopping transcription. When AI falls behind, pending time spans are combined into one catch-up request.

In Settings → Live summary and analysis, set the timed-summary interval, transcript chunk duration and number of completed chunks needed for a chunk summary. Chunk summaries run in the Analysis workspace; the growing transcript chunk is excluded until it finishes.

In AI context settings, Segment summary controls context for timed and chunk summaries. Previous summary blocks and running memory can provide continuity. Open Running memory below the relevant summaries to review its overview, key points and evidence ranges. Edit the JSON and choose Save only when you want to change it.

To include earlier summaries, enable Previous segment summaries under AI context settings → Segment summary. Then set Timed summary context and Chunk summary context in Live summary and analysis. Each count defaults to 1; set it to 0 to omit earlier blocks. Running meeting memory is a separate option.

Analyze and translate speech

Live analysis uses your configured AI provider, separately from local speech recognition. It combines automatic translation, summaries of completed chunks and selective analysis. Requests send the source text and enabled context to your provider and may incur charges.

  1. Select Live analysis in Meeting Control to open the Analysis workspace. The columns show Live transcript, Live analysis and, when a selective result exists, Selective analysis.
  2. Choose your target language, including a custom language name. Turn Summary and Translation on or off to choose the outputs you need. Both start enabled.
  3. Select Start live analysis. If a transcript already exists, choose its starting chunk. Choosing the same starting chunk resumes the current results; choosing a different one clears live results for every target language and resets chunk-summary running memory.
  4. Translation follows its interval countdown. Chunk summaries wait for completed chunks and combine all pending completed chunks once their minimum count is reached.
  5. Select transcript text and choose Analyze selected text, Analyze time range or Analyze all. A selective request can return a summary and translation together. Double-clicking keeps normal word selection.
  6. Use Source to inspect a result's input and Update to regenerate it with the current target language and output switches. Update becomes available after a live chunk finishes. Cancel stops the block's pending request while keeping its previous result.
  7. Select the active live-analysis button to pause automatic work. Selective requests remain separate. Hiding the Analysis window keeps active work running while another app window stays open.

In Settings → Live summary and analysis, translation defaults are 5 seconds between requests, up to 50,000 new characters and 200 preceding-context characters. Context supports continuity and is not translated again. Review Live translation, Selective analysis and Segment summary separately in AI context settings.

Use the new and context character-count links in the lower panels to inspect submitted text. Pending counts include running and queued requests; elapsed time includes time in the queue. Changing target language cancels pending analysis requests and keeps earlier completed results.

Clear selective analysis cancels and removes selective results while live work continues. Clear live analysis removes results from a chosen chunk onward for every target language and resets chunk-summary running memory. These actions rewrite saved results; back up anything you need first.

Arrange your reading space

In Settings → Other settings, adjust Display size for transcript, summary, chat and translation text, and Interface size for controls and dialogs. Both range from 8 to 14 points; Display size defaults to 11 and Interface size to 10. Fonts offers ten choices per interface language. Changes apply immediately and save automatically; unavailable fonts use the language default.

Use Block title color → Choose color in Other settings to change block headings. The color applies to existing and new blocks. Navigating to a block still highlights its title row so you can find it quickly.

Use Hide or a sidebar toggle to hide a column without deleting its content. Restore it from the sidebar. Fold all and Unfold all control the blocks in each column; Summary and Translation sections also fold independently. Hold Ctrl and scroll over a text pane to zoom it.

In the main transcript, Summary opens the matching timed summary. In the Analysis transcript, Analysis opens the matching live result. These links reveal and unfold existing results without sending a new AI request.

Right-click selected text or a block title for Ask AI, Analyze selected text, Ask AI to explain or Ask AI to summarize. The explanation and summary actions attach the selected content as a file and send it to AI chat. With no selection, a block-title action uses the whole block, including folded content.

Choose saved audio quality

Settings → Other settings → Audio quality controls saved meeting WAV audio. Capture settings → Audio quality controls video soundtracks independently. Select Save in Capture settings to apply video choices. Both offer Low, Balanced, High and Very high, with Balanced as the default. Higher quality uses more storage. WAV changes apply when saving next starts or resumes; video changes apply to the next recording. These choices do not change speech recognition quality.

Capture screenshots and visual sources

Audio and visual sources are selected independently. You can capture useful screen content without starting audio recording.

  1. Open Screenshot source to select any combination of the whole desktop, available application windows and cameras. Use Preview to check a source, then select Confirm.
  2. Select Capture window for a screenshot of each checked source. Select Capture area to drag a rectangle on screen; MeetSimpler minimizes during area selection.
  3. For repeated capture, open Capture settings and choose the interval, then select Save. Check your screenshot sources, then select Auto capture. Click the active capture button to stop.
  4. Leave Save only when the image changes enabled to reduce repeated automatic screenshots. The default change threshold is 10%; lower values save smaller changes. Automatic capture compares each source with its last saved image. Manual captures always save.
  5. Select Capture folder to view saved screenshots under visual_capture_data/screenshots inside the meeting folder, with a separate subfolder for each source.

When a selected window closes or another screenshot source fails, it is removed from the screenshot selection. Automatic capture continues with the remaining sources. If none remain, choose Screenshot source, confirm an available source and start Auto capture again. Screenshot failures do not stop video recording.

Changing screenshot sources while Auto capture is on restarts the capture interval with your new selection. If saving fails, automatic capture stops. Check the meeting folder's availability and free space, then start Auto capture again.

Capturing screenshots saves images locally. To use selected images in AI chat or summaries, add them through Meeting context config.

Record video from selected sources

  1. Before recording, open Capture settings to choose resolution, frame rate, video quality and audio quality, then select Save. Video defaults are 720p, 10 fps and Balanced; changes apply to the next recording.
  2. Choose Audio sources before starting. The selected microphone and output are mixed into every MP4. Select None in the audio source picker to record without sound.
  3. Select Record video to open Video source selection. Check one or more desktop, application window or camera sources. Video choices are independent of screenshot choices.
  4. Use Preview beside a source to check it, then select Start recording to record all checked sources. Each source saves to its own MP4 file.
  5. Click the active video recording button to stop. Wait for its Saved status before opening the files.
  6. Select Capture folder. MP4 files are saved under visual_capture_data/videos inside the meeting folder, with a separate subfolder for each source.

Video recording does not automatically add its frames to AI summaries.

A camera being recorded is unavailable for screenshots or Preview until recording stops. Desktop and window screenshots can continue.

Audio and video source changes apply to the next recording. The current recording keeps the sources selected when it started.

Summarize speech and visuals together

  1. Open Meeting context config and add selected screenshots, other images, PDFs or supporting notes.
  2. Open Settings → AI context settings and select Customize. Enable Meeting context files for each summary type that should receive those files, then select Save.
  3. Use an AI provider and model that support the images or PDFs you include. Generate a partial or final summary, or let configured automatic summaries run.
  4. For AI chat, enable Meeting context: On and the context files setting for AI chat. Enable Transcript context: On when you also want the confirmed transcript included.

For example, ask for a summary that connects a slide's key points with the spoken discussion. Check the result against both sources. Selected files go to your configured provider; saving screenshots does not upload them automatically.

Name and organize meetings

Use Rename meeting folder to generate descriptive folder suffixes from the confirmed transcript. Choose a suggestion, edit it if needed, then select Confirm and rename. You can also enter a custom suffix without an AI request.

Generating names or confirming a rename ends an active meeting and saves its records. You can edit the base folder name and an optional suffix. Review the final name before confirming; the app reloads the renamed folder so its records stay together.

Retrieve your meeting records

Your records are saved locally in the meeting parent folder chosen during setup. Each meeting has its own timestamped folder. You can reopen that folder in MeetSimpler or read its saved files in Windows File Explorer.

Reopen an earlier meeting

  1. If a meeting is running, select Click to stop meeting and wait for saving to finish.
  2. Select Load meeting folder in Meeting Control. Browse to your meeting parent folder and choose the individual meeting folder, not the parent folder or a subfolder inside the meeting.
  3. Wait for the records to load. Review Live Transcript, then select AI chat to read the latest saved chat session. Use Meeting folder in Meeting Control or AI chat to see the saved audio, transcript and summary files in File Explorer.

Loading a meeting lets you review its saved records. Select Resume meeting only when you want to continue capturing audio in that meeting.

Find saved screenshots and videos

Select Capture folder from the dashboard. Screenshots are under visual_capture_data/screenshots and videos are under visual_capture_data/videos, each organized into source subfolders. Keep the entire visual_capture_data folder with the meeting when backing up your records.

Retrieve a complete audio recording

  1. End the meeting and wait for saving to finish, or load the saved meeting you want to export.
  2. Select Export full audio in Meeting Control. Choose a destination and a WAV filename. Keep the destination outside audio_segments and use a name different from the original source audio files.
  3. Wait for the export to finish, then open the exported WAV file with your audio player. The export contains only audio that was actually saved; periods when audio saving was off cannot be recovered from the transcript.

Read, copy and back up text records

Markdown (.md) files are plain text. Open them with Notepad or a Markdown viewer, then copy the transcript, summary or chat text into your notes or a document. You can read these saved files without generating another AI response.

To keep a restorable backup, wait for recording, AI requests and saving to finish, then copy the entire individual meeting folder, including all files and subfolders, to your backup location. This preserves chat history, audio, analysis, screenshots, videos and meeting state. Use Load meeting folder to reopen the copied meeting later.

If a record is missing

Confirm that you opened the correct meeting folder. Saved audio is available only if recording was on or audio was imported. Transcript text requires successful speech recognition, and summaries require successful AI generation. Check System log for saving or processing errors. Signing in on the website does not retrieve these local files.

For your next meeting

Select Start another meeting to prepare a fresh meeting, confirm the audio sources and then select Start meeting. Use Meeting context config to add an agenda, names or supporting notes, and review the AI context settings before sending that information.

To revisit earlier work, select Load meeting folder and choose that meeting's individual folder inside your parent folder. Review the restored records, or select Resume meeting when you want to continue capturing in the same meeting.

If you already have a recording, use Import audio and follow its file or folder selection and transcription instructions instead of starting live capture.

Common setup problems

For error details, open Settings → Other settings → Account and support → Open system log. Check the relevant entry or STT installation log before retrying. Keep API keys and private meeting content out of support messages.

MeetSimpler will not open, or security software blocks it

Antivirus, monitoring or endpoint protection software, Microsoft Defender SmartScreen, and Windows Smart App Control may block the app or its STT components when a file is unsigned, its publisher cannot be verified, or it has little reputation. Check the actual warning or block history to identify the cause.

  1. Confirm that your download came from the official Windows downloads link in this guide. Only allow files you trust after reviewing the warning.
  2. Open your security software and review its alerts, quarantine or blocked-app history. For Microsoft Defender Antivirus, open Windows Security > Virus & threat protection > Protection history. Note the blocked file path; it may be MeetSimpler.exe or a separate STT runtime or library.
  3. If the software supports it, adjust its app permissions or trusted-app settings to allow the verified file. Use a specific allow rule or exception for the affected file or required folder, rather than disabling protection for the whole computer. Restore a quarantined file only if you trust it.
  4. Restart MeetSimpler and retry the affected operation. If STT files were removed, use the model manager to repair or reinstall the selected model after resolving the block. On a work or school computer, ask your IT administrator to review any enforced security policy.

For a Microsoft Defender SmartScreen warning about an unrecognized app, review the source and publisher first. If you trust the download and the options are available, select More info, then Run anyway. Managed devices may prevent this action.

Windows Smart App Control has no per-app allow option. An antivirus exception does not override its block. Check Windows Security > App & browser control > Smart App Control to identify this protection, then contact MeetSimpler support about a signed version of the blocked component or ask your IT administrator for guidance.

How do I change the installation folder when reinstalling MeetSimpler?

To change the app's installation folder, use "Uninstall the existing app, then reinstall" if that option is offered by your installer, then choose the new folder. The installer removes the existing app before installing in the selected location. If the option is unavailable or folder selection is skipped, uninstall MeetSimpler through Windows first, then run the installer again using the steps below.

  1. Close MeetSimpler after any recording, processing and saving have finished.
  2. On Windows 11, open Settings > Apps > Installed apps. Find MeetSimpler, select the three-dot menu, then Uninstall and follow the prompts. On Windows 10, use Settings > Apps > Apps & features.
  3. After uninstallation finishes, run the MeetSimpler installer again. Choose your preferred folder on the installation-folder screen and complete setup.

The installation folder contains the application files. The meeting parent folder for recordings and records is configured separately in MeetSimpler Settings.

Browser sign-in finished, but the desktop app is still waiting

Check that you began Google or GitHub sign-in from the desktop app and that the browser reported a successful desktop handoff. A normal website login does not pair the app. If the pairing expired or was cancelled, return to the desktop app, cancel the pending browser sign-in and begin a new attempt.

No transcript text appears

Check that the meeting is running, your speech model is installed and selected, and STT has finished loading. Open Audio sources and confirm the microphone or output you need. Speak or play audio on that source. If STT was stopped, use the STT control to load it again. If the model reports an error, read the status and resolve the installation or device issue.

I hear the call, but only my voice is transcribed

Your microphone captures your voice; it does not automatically capture the call's playback. Select a system or app output in Audio sources as well as your microphone, then Confirm. If the meeting app is missing, open it and start audio playback, then refresh the source picker.

Speech appears twice

Check whether loudspeaker playback is reaching your microphone while the same audio is also captured through an output source. Try headphones and select only the sources needed for the meeting.

A speech model will not install or load

Read the model manager's status. Check the internet connection and free disk space, then retry the install or reinstall action it offers. If CUDA is unavailable, use CPU only and install a model supported for CPU. Reopen Settings if the app could not complete its model check.

Security software can also block STT downloads, package installation or backend libraries even when MeetSimpler opens normally. Open System log and its STT installation log to review the failure and affected file path, then check your security software for a matching block before retrying. A successful CUDA check does not rule out a security block.
